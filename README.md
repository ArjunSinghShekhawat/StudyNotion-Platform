# Overview

Study Notion is an advanced education platform aimed at connecting students and instructors. It provides various functionalities including user authentication, course management, profile management, and more. The backend is powered by Spring Boot and SQL database to ensure scalability and robustness.

# Features

## User Authentication
Secure login and signup with role-based access control (Admin, Instructor, Student).
JWT-based authentication for secure API interactions.

## Course Management
Create, update, and delete courses with detailed descriptions and pricing.
Upload course thumbnails and other resources.

## Category Management
Admins can create, update, and manage categories for courses.

## Profile Management
Users can update their profiles with personal information.
Secure handling of user data.

## Section and Subsection Management
Instructors can manage sections and subsections of their courses.
Upload videos and resources for subsections.

## Ratings and Reviews
Students can leave ratings and reviews for courses.
Admins have control over reviews for quality assurance.

## Contact Queries
Users can submit queries via a contact form.
Admins can review and respond to these queries.
